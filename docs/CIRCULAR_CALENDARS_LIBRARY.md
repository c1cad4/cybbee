# Круговые календари, книги, цветение и чат

## Календарь
Визуальная схема создана как самостоятельный SVG по идее присланных пользователем круговых календарей: кольца, числовая шкала, цветные стадии и стрелка. Снимки бумажных календарей не копировались как изображения. Годовой круг учитывает полушарие и реальные длины месяцев; декоративная тема не изменяет биологические расчёты. Демонстрация сезонов меняет дату просмотра, не журнал. После демонстрации кнопка «Сегодня» возвращает настоящую дату.

Для Apis mellifera день 0 обозначает кладку. Ориентир выхода матки — 16–17 суток, трутня — около 24. При переносе личинки её возраст после вылупления задаётся отдельно (0–24 часа); расчёт вычитает 3 суток яйца и этот возраст. Даты округляются до календарных суток, а не обещают точный час. Запечатывание и стадия куколки показаны как ориентиры. Спаривание, зрелость трутня и начало яйцекладки по одной дате не гарантируются.

Источники: Penn State https://extension.psu.edu/beekeeping-cell-builder-basics ; UGA https://fieldreport.caes.uga.edu/publications/B1045/honey-bees-and-beekeeping/ ; University of Arizona https://extension.arizona.edu/publication/honeybee-series-honeybee-basic-biology . У источников различается представление дня запечатывания; отображается окно, а не универсальная точная минута.

## Библиотека
Четыре источника: FAO 2009 (192 страницы), FAO 2003 (65), RHS (5), РГАУ-МСХА 2023 (720, русский язык). Публикации открываются/скачиваются с сайта издателя; CybBee их не зеркалирует и не продаёт. Язык оригинала явно указан. Проверены официальные карточки и PDF-ссылки.

Собственный PDF до 20 МБ можно добавить локально; лимит — 5 книг. IndexedDB хранит файл только в браузере. Книга читается через PDF.js 6.4.299 с перелистыванием страниц. PDF.js, Worker, карты символов, шрифты и декодеры поставляются с приложением; книга не отправляется на сервер или в ИИ. После первичного открытия необходимые ресурсы кешируются для офлайн-чтения. Парольные/повреждённые PDF могут потребовать другого просмотрщика. Оригинальный файл можно скачать отдельно; облачная копия журнала не включает книги. Очистка браузера удаляет локальные книги.

PDF.js — Mozilla, Apache 2.0. Версия и SHA-512 архива закреплены в hosting/pdfjs.lock.json. Зависимости скачиваются скриптом при сборке; в GitHub они не хранятся как тысячи готовых бинарных файлов. `bash hosting/scripts/build.sh` скачивает закреплённый пакет, проверяет хеш, генерирует Worker и собирает dist. Применённая лицензия — docs/licenses/PDFJS-LICENSE.txt. В исходном репозитории Sites подготовленные ресурсы сохранены вместе с точной версией артефакта.

## Цветение
Добавлены 16 растений с сезонными окнами RHS для Великобритании. Шкала — месяцы, не точные локальные даты. Окна других стран не вычисляются переносом полушария. Для конкретного региона пользователь фиксирует фактическое начало/конец цветения и заметку. Эти записи входят в журнал, экспорт, восстановление и ручную облачную синхронизацию как `flowerings`; старые журналы без этого массива поддерживаются. Начало не может быть позже окончания.

## Чат и анимации
Чат проверяет ленту раз в 15 секунд, когда вкладка видима и сеть доступна. Новые записи показываются отдельной кнопкой, не стирают черновик и не сбрасывают читаемую страницу. Нет выдуманных счётчиков «онлайн» или мгновенной WebSocket-доставки. Ctrl/Cmd+Enter отправляет запись; действуют прежние авторизация и серверные ограничения. Пользовательские сообщения не переводятся автоматически.

Анимированы пчёлка, стрелка и появление карточек. Prefers-reduced-motion и локальная настройка «Уменьшить движение» отключают движение; биологические даты не меняются. Исправлен конфликт CSS display:flex с hidden для скрытых полей. Новые экраны, пояснения календаря и библиотеки, заголовки и общие вступления переведены на 10 языков. Полные памятки и часть старых ошибок ещё русские; язык книг остаётся оригинальным.

## Проверка
Тесты проверяют перенос года/високосную дату, возраст при переносе личинки, сроки выхода, SVG-подписи, PDF-заголовок и размер, восстановление наблюдений цветения, серверную синхронизацию нового массива, уведомление о новых записях и бинарные ресурсы PDF.js. Browser QA выполнен на локальной тестовой базе: тестовый PDF, первые страницы русской книги на 720 страниц, переключение календаря и языков. Пользовательская настоящая пасека не изменялась; проверка физических Android/iPhone ещё предстоит.
