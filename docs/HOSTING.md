# CybBee в интернете

Публичный адрес: https://cybbee.quickibex5.chatgpt.site

Развёрнуто в Sites на Cloudflare Workers с постоянной базой D1. Отдельный платный VPS не приобретался. Доступность и лимиты Sites зависят от плана/рабочего пространства; бесконечный бесплатный ресурс не обещается.

Посетители могут открывать приложение, читать общую ленту и карту без входа. Для публикации, удаления своих записей, точки на карте и облачного журнала нужен вход через ChatGPT. Сервер получает подтверждённый платформой идентификатор и проверяет владельца. Email пользователя не публикуется в ленте.

## Подключено
- Общая база записей и приблизительных точек, одна точка на пользователя, удаление своей точки.
- Удаление своих записей, жалобы. После трёх разных жалоб запись автоматически скрывается. Полноценная панель модератора и рассмотрение жалоб ещё нужны.
- Облачная копия личного журнала, доступ только владельцу. Сохранение и загрузка вручную; версия защищает от перезаписи чужих изменений с другого устройства.
- Серверный расчёт $10/месяц, $100/год в SOL или CicadaFarm; точные целочисленные суммы, проверка Solana Pay. Приём оплаты отключён до готовности платного доступа и условий продаж.
- Статические файлы PWA, сезонные темы, языковые настройки, WebLLM на устройстве, карты OSM.

ИИ сам не ищет в интернете; отдельный поиск открывает поисковик. Полный перевод справочника, нативные установщики и профессиональные Pro-функции ещё не завершены. Локальная модель требует совместимого WebGPU-браузера и памяти.

## Исходники
`hosting/worker/api.js` — облачные маршруты; `hosting/worker/index.js` — собранный Worker с встроенными файлами приложения; `hosting/drizzle/` — неизменяемые применённые миграции. `hosting/scripts/generate-worker.py` обновляет встроенные файлы из `app/`. Секреты не хранить в Git. Проект Sites и его исходники сохраняются отдельно от GitHub; GitHub содержит зеркальную копию серверного кода.

Облачная БД и записи пользователей в GitHub не публикуются. Локальный Python-сервер остаётся средством разработки, а не публичным сервером.

Проверено: публикация второй версии Sites успешна; D1 содержит bee_posts, bee_points, bee_reports, bee_journals, bee_invoices; анонимная лента загружается; вход открывает официальный экран OpenAI. Полную запись/чтение от реального аккаунта ещё нужно проверить после входа пользователя. 7 тестов клиента, 8 тестов Python и 3 проверки маршрутов Worker прошли.
