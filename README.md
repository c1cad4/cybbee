## Назначение

Наблюдения фермы и пасеки с источником и временем. Этот репозиторий содержит библиотеку наблюдений и отдельное приложение CybBee в `app/`.

## Начать работу

Репозитории размещаются рядом в одной рабочей папке. Для полного окружения используйте `cybOS/tools/bootstrap.py` и `cybLaunch/launcher.py`; точные ревизии публикуются в lock-файлах интегратора.

```bash
cd cybbee
cargo test --locked -j 4
cargo run --locked --example demo
```

## Структура

- `src/` — публичная библиотека и её тесты.
- `Cargo.lock` — воспроизводимые зависимости.
- `examples/` — небольшой проверяемый пример; данные с меткой demo являются фикстурами.
- `docs/ECOSYSTEM.md` — границы компонента и связи.

## Текущий уровень

Это проверяемые контракты и локальная логика. Подключение реального оборудования, VPN или сети выполняется отдельными адаптерами; библиотечная проверка не подтверждает работу отсутствующего устройства.

## Приложение CybBee

Первая рабочая PWA: ульи, осмотры, календарь, памятки, карты и экспорт журнала. [Статус и этапы развития](docs/APP_ROADMAP.md).

```bash
python3 -m http.server 8772 --bind 127.0.0.1 --directory app
```

Откройте http://localhost:8772. Установка на телефон требует HTTPS. Нативные установщики и ИИ ещё не подключены.
